# YARD ZERO

ブラウザで遊べる3D FPS（モンスター掃討戦）。WebGL2だけで動き、外部ライブラリは使っていません。

**遊ぶ：** https://shinopipi.github.io/game_fps/

## iPhoneでアプリとして使う

1. 上のURLをSafariで開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の「YARD ZERO」アイコンから起動（全画面・横画面で遊べます）

一度起動すればオフラインでも遊べます。

## 操作

- **スマホ**：左側ドラッグ＝移動／右側ドラッグ＝視点／射撃・ADS・装填・切替・拾う・跳ぶ・屈むはボタン
- **PC**：WASD・マウス・左クリック＝射撃・右クリック＝ADS・R＝装填・Q＝武器切替・E＝拾う・Shift＝ダッシュ・Space＝ジャンプ・C＝しゃがみ

## ファイル

- `index.html` … ゲーム本体（描画・ゲームロジック・UIすべて）
- `tex/` … 素材テクスチャ（`a*.jpg` 色、`n*.jpg` 凹凸と光沢）
- `manifest.webmanifest`, `sw.js`, `icons/` … ホーム画面アプリ化とオフライン対応

## 更新したとき

`sw.js` の `CACHE` の番号（`yard-zero-v1`）を1つ上げると、インストール済みのアプリにも新しいファイルが確実に届きます。
